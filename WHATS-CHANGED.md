# What's changed

This page lists the changes to the Queens Resource Map that a reader would notice: new pages and map layers, new resources, changes to how hazards are ranked, and corrections when we published something wrong. Newest first. The NYC Preparedness and Recovery Institute (PRI) created the map in collaboration with BetaNYC. It is still being built, so changes are frequent.

- **History begins:** 2026-09-23, the day the first version of the map went online. Every change since then is listed.
- **Data refresh:** hazard and resource data weekly, on Mondays, from City and State sources; emergency alerts from Notify NYC every two minutes while the map is open. Routine refreshes are not listed.

To share feedback or get a resource added, use [the feedback form](https://forms.gle/itJupzxdb6mhG7dr9). To report a bug in the map or ask for a new feature, [open an issue on GitHub](https://github.com/BetaNYC/q-map/issues).

## 2026-11-12: A What's changed page

- **Tags:** Site
- **What changed:** A new page lists every change to the map a reader would notice, newest first, with a filter for site changes and data changes. The home page links to it.
- **More detail:** [What's changed on GitHub](WHATS-CHANGED.md)

## 2026-11-11: Cooling options get their own category

- **Tags:** Site, Data
- **What changed:** Places to keep cool are now their own resource category, with their own color on the map. Locations that store hazardous materials were added, and the text now refers to NYC Emergency Management.
- **More detail:** [Pull request](https://github.com/BetaNYC/q-map/pull/45) · [Colors](https://github.com/BetaNYC/q-map/pull/47)

## 2026-11-05: Flood layers with legends, and resources shown from the start

- **Tags:** Site, Data
- **What changed:** New map layers for tidal flooding and FEMA flood zones, and legends for the map layers. Stormwater flooding depths are grouped into fewer categories. A district page now opens with some resource categories already on the map.
- **More detail:** [Pull request](https://github.com/BetaNYC/q-map/pull/43)

## 2026-11-04: Queens Public Library branches

- **Tags:** Data
- **What changed:** Queens Public Library branches are now listed as resources, with name, address, phone and a link to each branch's hours, from the library's own list on NYC Open Data. A branch the library opens or closes reaches the map at the next refresh.
- **More detail:** [Pull request](https://github.com/BetaNYC/q-map/pull/42)

## 2026-10-26: Hazards ranked the way PRI specified

- **Tags:** Data, Site
- **What changed:** The way each district's hazards are ranked, and the resource gaps chosen for each district, now follow PRI's specification. The introduction on the home page was rewritten.
- **More detail:** [Ranking](https://github.com/BetaNYC/q-map/pull/38) · [Follow-up](https://github.com/BetaNYC/q-map/pull/39) · [Introduction](https://github.com/BetaNYC/q-map/pull/41)

## 2026-10-21: Clearer map points and a tighter map

- **Tags:** Site
- **What changed:** Points on the map change when you point at them, and a point's popup names where the resource comes from. The map's zoom and the area you can pan to were adjusted.
